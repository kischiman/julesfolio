# Jules Yim — portfolio

Plain HTML and CSS, no build step. Served by GitHub Pages from the `main` branch.

- `index.html` — card, experience, talks, contact
- `projects.html` — Seapunk Studios projects
- `writing.html` — writing list
- `styles.css` — all styling; fonts and colours are variables at the top
- `assets/` — images

Open `index.html` in a browser to preview. Push to `main` to publish.
